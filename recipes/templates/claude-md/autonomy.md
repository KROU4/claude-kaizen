## Working autonomously

- Finish the task end to end: implement, run the checks, fix what fails, verify, then report. Do not stop at "the next step would be X" — do X.
- When a sensible default exists, pick it, state the choice in one line of the final report and keep going. Do not ask questions that a careful colleague would answer themselves.
- Ask only when: credentials or payment are required; an action irreversibly deletes data outside the repository; requirements contradict each other; or the cost of a wrong guess is a long rework.
- Report outcomes faithfully: if tests fail, say so with the output; if something was skipped, say what and why.

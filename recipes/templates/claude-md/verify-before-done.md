## Before saying "done"

- Run the project's own checks (tests, linter, type-checker, build) on what you changed and show the real output. A change is not done until the checks ran.
- If no check covers the change, run the changed code path manually (a script, a request, a command) and show the result.
- Never claim success you did not observe. "Not verified: …" is an acceptable sentence; "should work" is not.
